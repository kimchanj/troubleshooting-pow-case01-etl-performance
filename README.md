# Troubleshooting Proof of Work — Case #01
## ETL Performance

이 저장소는 **진행 중인 Case #01 연구**다. 실제 엔터프라이즈 ETL/Batch 성능 문제를 경험하면서 시작된 질문과 문제 해결 과정을 작업증명(Proof of Work)으로 남기려 한다.

**STEP 1 — Synthetic ETL Target Design**을 진행하고 있다. 재현 가능한 최소 Spring Boot 기반과 Oracle 실험환경 위에서 공개 가능한 ETL 문제 구조를 설계했으며, ETL 기능, 측정, 실험 또는 성능 개선 검증은 아직 수행하지 않았다.

## 앞으로의 방향

공개 가능한 문제 범위와 관찰 대상을 정하고, 증거를 수집하며 가설과 실험을 기록하려 한다. 구체적인 시스템 구조, 도구, 측정 항목과 검증 기준은 아직 결정하지 않았다. 성능 개선 수치나 실험 결과도 아직 없다.

이 저장소에는 Case #01 하나를 담는다. 이후 Case는 각각 독립적인 저장소로 관리한다. 진단도구는 각 Case의 필요에 따라 설계하고, 여러 Case에서 실제로 반복되는 패턴이 발견된 뒤 공통화 여부를 검토한다.

회사나 시스템을 식별할 수 있는 정보, 내부 데이터, 보안정보와 실제 회사 소스 코드는 포함하지 않는다. 실제 경험은 공개 가능한 일반적인 기술 구조로 추상화한다.
