# Career Hypothesis

기록 시점: 2026-09-30 / STEP -1 — Origin

## 현재 가설

원인을 알 수 없는 시스템에서 증거를 수집하고 문제를 좁혀가며 답을 찾는 능력이 내 경쟁력 중 하나일 수 있다. 이 가설에서 **Performance Troubleshooter**라는 커리어 방향을 생각하게 되었다.

이는 확정된 직업 정체성이나 이미 증명된 전문성에 대한 선언이 아니다. 실제 ETL/Batch 성능 문제 해결 경험에서 시작된 가설이다. 한 경험에서 느낀 가능성이 다른 문제와 플랫폼에서도 이어질지는 아직 모른다.

## 확인하고 싶은 것

- 문제를 나누고 측정할 대상을 선택한 판단을 증거로 설명할 수 있는가?
- 관찰 사실과 추측을 구분하고, 가설에 맞지 않는 결과가 나왔을 때 판단을 수정할 수 있는가?
- 해결했다고 판단한 근거를 다른 사람이 검토할 수 있게 남길 수 있는가?
- 이후 서로 다른 Case에서도 이런 문제 해결 방식이 도움이 되는가?
- AI의 도움을 받는 과정에서 내가 내린 판단과 AI의 기여를 구분해 설명할 수 있는가?

Case #01만으로 이 가설 전체를 결론 내리지 않는다. Case별 기록을 축적하며 무엇이 반복되고 무엇이 해당 상황에만 유효했는지 살펴본다. 가설을 지지하지 않는 경험도 남기고, 커리어 방향에 대한 생각이 바뀌면 그 이유와 시점을 Journal에 기록한다.

현재는 이 방향의 적합성, 다른 환경으로의 확장 가능성, 이를 평가할 충분한 기준을 아직 모른다. 구체적인 검증 방식은 향후 Case의 문제 범위를 정하면서 결정한다.
